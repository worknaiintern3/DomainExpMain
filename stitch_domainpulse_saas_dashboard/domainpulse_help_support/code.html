Understanding Domain Data

Technical taxonomy and metadata fields aggregated across the portfolio engine.

database
Registrar Entity

The accredited commercial or institutional entity (e.g., Cloudflare, Namecheap, GoDaddy) managing the domain’s registration record with the upstream registry.

Registration Date Timestamp

The ISO 8601 UTC timestamp identifying when the domain was first initialized in the registry database, establishing portfolio asset age.

Expiry Date Countdown

The definitive registry deadline when the active delegation term terminates. Determines the Critical (≤7d) and Warning (≤30d) triggers.

Nameservers DNS Delegation

Authoritative DNS hostnames (NS records) tasked with answering zone queries and resolving your web applications, mail exchanges, and API endpoints.

DNSSEC Security Extension

Domain Name System Security Extensions. Uses cryptographic digital signatures to verify that resolver query responses have not been spoofed or poisoned.

RDAP Protocol IETF RFC 7480-7484

Registration Data Access Protocol. The modern RESTful JSON standard replacing unstructured text WHOIS, delivering machine-verifiable status flags and dates.

WHOIS Legacy Port 43 TCP

The legacy plain-text protocol. Utilized as a secondary fallback query mechanism if an authoritative ccTLD registry lacks public RDAP endpoints.

SSL Certificate X.509 TLS

Cryptographic handshake telemetry gathered via HTTPS port 443, displaying Certificate Authority (CA) issuer, cipher validity, and expiration window.

Understanding Pricing

Breakdown of portfolio cost vectors, registrar discount dynamics, and multi-year forecasting.

analytics
Year 1 Entry
Registration Price

Initial fee required to secure a brand new domain name. Often heavily discounted by commercial registrars for promotional acquisition.

Recurring Annual
Renewal Price

The standard base rate charged each subsequent 12-month period to maintain registration. Essential for accurate annual operational budgeting.

Migration Fee
Transfer Price

The fee charged to move a domain between registrars. Transfer rules, included renewal periods and eligibility vary by TLD and registrar.

Delta Metric
Renewal Markup

The financial gap between initial promotional pricing and regular renewal costs. Highlights hidden subsequent-year price hikes.

Long-Term Model
5-Year Ownership Projection

Formula: Cost = Y1_Registration + (4 × Y_Renewal). Provides executive clarity on true multi-year cash outlay beyond promotional year-one hooks.

DomainPulse interrogates public registry databases to pull: authoritative Nameservers (NS), current Registrar identity, exact UTC Creation & Expiry timestamps, DNSSEC signing status, and active TLS/SSL certificate dates via HTTPS port 443 inspection.

RDAP (Registration Data Access Protocol) is the standardized successor to WHOIS created by the IETF. Unlike older text-based query systems, RDAP responses are formatted in strict JSON, support secure REST transport over HTTPS, provide authenticated access tiers, and standardize internationalized domain characters.

WHOIS is a legacy protocol dating back to RFC 812 that queries databases on TCP Port 43. Because WHOIS outputs unstructured plain text with varying schema per registrar, modern platforms prioritize RDAP for programmatic parsing.

Automated health triage uses exact day-deltas calculated against UTC midnight: Expirations ≤ 7 days are categorized as Critical; expirations between 8 and 30 days trigger Warning; and domains with > 30 days remain Healthy.

Registration pricing applies exclusively to the initial 1-year acquisition and frequently includes promotional subsidies. Renewal pricing is the non-discounted recurring rate charged annually to retain the domain. DomainPulse highlights the Renewal Markup so you know the long-term carrying cost.

Wholesale wholesale registry fees (e.g. Verisign for .com) are identical across registrars, but consumer prices vary due to retail profit margins, bundled value-adds (such as privacy protection or DNS hosting), ICANN fee handling, and corporate discount tiers.

We combine Year 1 initial registration cost with 4 consecutive periods of base renewal pricing. This neutralizes misleading initial discounts and gives finance teams an accurate 5-year cost projection.

DNSSEC attaches cryptographic signatures (RRSIG, DS records) to DNS entries. When resolving a domain, recursive resolvers verify the cryptographic chain of trust, preventing man-in-the-middle attacks and DNS cache poisoning.

The SSL inspector initiates an automated TLS handshake to report Certificate Authority (e.g., Let's Encrypt, DigiCert, Cloudflare), valid-from and valid-to timestamps, remaining active validity days, and protocol cipher strength.

Data Sources & Limitations

DomainPulse is engineered for transparent technical intelligence. Review the boundaries of our automated data collection:

  • check_circleDomain registration information may be retrieved from RDAP and compatible WHOIS sources. Available fields vary by registry, registrar, privacy policy, and TLD.
  • check_circleDNS information is based on publicly resolvable DNS records when available.
  • check_circleSSL/TLS information is retrieved when the target domain exposes an accessible HTTPS endpoint.
  • check_circleRegistrar pricing may use live sources where supported and reference datasets where live provider APIs are unavailable.
  • check_circleAvailability checks can occasionally be inconclusive if upstream registry services are rate-limit or throttle connections.
  • check_circleDomainPulse does not guarantee registrar pricing, promotional terms, or availability guarantees.
  • check_circleActual registration, renewal, transfer pricing, promotions and taxes should be verified with the provider before purchase.

Troubleshooting Common Issues

Quick resolution steps for common technical and network lookup errors.

construction
error

Domain Lookup Failed

Verify the domain syntax has no leading protocols (https://) or trailing slashes. Re-run the query or verify your local internet connection.

cloud_off

RDAP Data Unavailable

RDAP data may be unavailable, incomplete or rate-limited for some registries or TLDs. Try again later or use available fallback registration information.

sync_problem

DNS Records Not Found

DNS changes may take time to propagate depending on TTL, resolver caching and provider configuration.

lock_reset

SSL Information Unavailable

The target host may not support TLS/HTTPS or has web application firewall (WAF) rules filtering diagnostic automated handshakes on port 443.

file_download_off

CSV / JSON Import Failed

Verify your file format. CSV imports require a lowercase domain column header. Check that date strings use standard ISO 8601 formatting (YYYY-MM-DD).

content_copy

Duplicate Domain Warning

The domain already exists within your active workspace. To update records, select the existing row in My Domains and trigger a manual metadata refresh.

money_off

Pricing Unavailable for TLD

Niche country-code (ccTLD) or specialized sponsored extensions may lack standardized retail benchmarks. You can assign custom estimated costs in the domain settings drawer.
